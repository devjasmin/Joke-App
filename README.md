**WITZE-APP**

Diese Witze-App lädte zufällige Witze auf deutsch von einer API. Es können beliebig viele Witze geladen werden und
alle Witze können gespeichert werden; jedoch niemals den gleichen Witz zwei Mal. 
Die Witze können einzeln oder alle auf einmal gelöscht werden. (auch in localStorage)
Mit localStorage bleiben die Witze nach dem Schliessen erhalten.

Tech Stack
- **Frontend:** HTML5, CSS3 / SCSS
- **Logik:** JavaScript (ES6+, Fetch API, Async/Await)
- **Datenbank:** Browser LocalStorage

Installation & Start

Du kannst das Projekt ganz einfach lokal bei dir starten:

1. **Repository klonen:**
   ```bash
   git clone https://github.com
   ```
2. **In den Projektordner wechseln:**
   ```bash
   cd Joke-App
   ```
3. **Projekt starten:**
   Öffne die `index.html` direkt im Browser oder nutze eine Erweiterung wie *Live Server* in VS Code.
